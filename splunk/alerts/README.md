# Splunk Alert Configuration

This directory documents the scheduled alerts configured for the Windows SOC lab.

The alerts are based on Windows Security, Sysmon and PowerShell telemetry collected from the monitored Windows endpoint.

## Alert Workflow

Windows Endpoint
    ↓
Windows Event Logs / Sysmon / PowerShell
    ↓
Splunk Universal Forwarder
    ↓
Splunk Enterprise
    ↓
Detection Search
    ↓
Scheduled Alert
    ↓
Triggered Alerts
    ↓
Analyst Investigation

---

## 1. SOC - Windows Failed Logon

Detection: Windows Security Event ID 4625

Search:

index=* EventCode=4625

Configuration:

- Alert type: Scheduled
- Schedule: Every 5 minutes
- Time range: Last 5 minutes
- Trigger condition: Number of results > 0
- Severity: Medium
- Action: Add to Triggered Alerts
- Status: Enabled

Purpose:

Detect failed Windows authentication attempts and provide an alert for analyst review.

Investigation:

When the alert triggers, review the affected host, account, timestamp, source information and surrounding authentication activity.

## 2. SOC - Sysmon Process Creation

Detection: Sysmon Event ID 1

Search:

index=* sourcetype="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1

Purpose:

Monitor process creation activity on the Windows endpoint.

Investigation:

Review the process image, command line, parent process, user, process ID and surrounding activity.

## Alert Investigation Process

When an alert appears in Triggered Alerts:

1. Open the triggered alert in Splunk.
2. Review the original event and timestamp.
3. Identify the affected host and user.
4. Review the relevant Event ID.
5. Examine process, command line, network or authentication details depending on the alert.
6. Search surrounding events for additional context.
7. Determine whether the activity is expected or suspicious.
8. Classify the result as True Positive or False Positive when sufficient evidence is available.
9. Record the investigation result and relevant evidence.

---

## Alert Severity

Severity should reflect the potential impact and confidence of the detection.

The current Windows Failed Logon alert is configured with Medium severity for this lab.

Other alert severities should be documented according to their actual Splunk configuration rather than assumed values.

---

## Alert Validation

Alerts are tested against telemetry generated or observed on the Windows endpoint.

Validation includes:

- Confirming the detection search returns relevant events.
- Confirming the scheduled alert is enabled.
- Confirming the trigger condition is met when results are returned.
- Confirming the alert appears under Triggered Alerts.
- Reviewing the generated event for investigation details.
